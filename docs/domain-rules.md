# 领域边界

协调亚洲体育协会之间的人员资质、培训、交流名额和赛事指派。

现有领域资料围绕以下边界组织：

- 人员资质版本
- 交流申请
- 赛事岗位指派
- 利益冲突
- 替补与申诉

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 系统规则（src/exchange）

`src/exchange/` 实现可运行的人员交流与赛事指派系统，状态由只增事件流导出，
中断后从事件存储重放即可恢复。规则归属如下：

### 身份与材料（协会维护）

- 协会只能注册和修订本方人员；材料版本严格递增，旧版本永久保留。
- 材料包含：身份、培训、证书（项目/等级/有效期）、语言、签证期限、
  可服务项目、与参赛队已申报关系。
- 协会可以修订材料、提交例外申请，但不能独自批准本方人员的例外；
  例外只能由秘书处按失败条款逐条批准（`policy.py` 中的稳定代码）。

### 岗位与邀请（承办方提交、秘书处决定）

- 承办方即主办协会，提交岗位、时段、等级与语言要求、允许地域、
  分地域差旅名额、参赛队名单。
- 邀请在**发出当时**按有效材料重新评估并保存资格快照：
  证书决定时点有效且覆盖履责末日、等级达标、语言齐备、
  签证覆盖履责末日、地域允许、名额未满。
- 同时检查：与该人员其他在途安排（含待答复邀请）的时段重叠、
  最短休息间隔（`REST_INTERVAL_HOURS`）、候选人与参赛队关系。

### 答复、退出与赛程调整

- 同一邀请重复确认同样答复时，原样返回首次决定（幂等）。
- 答复内容矛盾（先接受后拒绝或反之）时，岗位立即暂停，
  由秘书处裁决维持原决定或采纳后答复；改口接受仅在无替补在途时恢复。
- 退出、赛程调整、撤岗只释放**尚未履行**的场次；
  已完成场次的执裁评价沿用邀请发出时的资格快照，事后材料修订不影响。

### 替补、申诉与持续待办

- 替补邀请只承接剩余场次（`covering_slots`），前任已完成的责任记录
  （评价、材料版本、例外批准链）随岗位保留并可解释。
- `todos()` 持续投影：证书即将到期/已过期、签证即将到期/已过期、
  需替补岗位、暂停岗位、材料失效后的在途安排复核、未裁决申诉。
- `explain()` 解释每次指派为何成立、检查了哪些条款、谁申请/谁批准了
  例外、首次答复内容、释放原因与场次、换人时保留了哪些责任记录。
- `organizer_view()` 面向承办方做最小披露：仅履职所需字段，
  不含关系明细、签证、培训及其他候选人信息。
